# C-Code

A structured collection of **C programming exercises**, algorithms, and problem-solving code.  
This repository is created to store C programs across multiple branches for learning, interview preparation, and practice.

## 📘 Repository Overview

This repo contains clean and organized C programs including:
- Basic C programs  
- Control statements (if-else, loops)  
- Functions & recursion  
- Arrays, strings, and pointers  
- Structures & dynamic memory  
- File handling  
- Data structures in C  
- Algorithm implementations  
- C coding interview problems  

You can check different branches for different categories and versions of code.
